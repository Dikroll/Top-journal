# Top Academy Journal (Unofficial Client)

Неофициальное приложение дневника для студентов **Top Academy**.
Проект предоставляет удобный интерфейс для работы с учебной информацией: расписанием, оценками и другими данными.

---

### О проекте

Top Academy Journal — это клиентское приложение, созданное для упрощения взаимодействия с учебным журналом.

Основная цель проекта:
• улучшить UX по сравнению с оригинальным решением
• предоставить быстрый и удобный доступ к данным
• создать современный и расширяемый интерфейс

---

**Важно**

Это неофициальный клиент и он:
• не связан с Top Academy
• не является официальным продуктом
• использует открытые/доступные API

---

### Основной функционал

- 📅 Просмотр расписания
- 📊 Отслеживание оценок
- 📚 Доступ к учебным материалом
- 📙 Отправка Домашних заданий
- 🔔 Оценка работы преподавателей
- 👤 Профиль пользователя

---

## 📦 Установка

### Android

Скачай готовый APK-файл из вкладки **Releases** и установи его на устройство.

---

### IOS _(только для macOS)_

1. Клонировать репозиторий:

```bash
git clone https://github.com/
```

2. Перейти в папку проекта:

```bash
cd journalweb
```

3. Запустить установку:

```bash
bash ./build-ios.sh
```

> Требуется установленный Xcode
